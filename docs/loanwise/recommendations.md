# LoanWise Recommendations

LoanWise recommendations are generated by the deterministic recommendation engine.

The recommendation engine considers applicant and loan-product factors such as:

- Credit score
- Debt-to-income ratio
- Monthly income
- Requested loan amount
- Preferred tenure
- Employment type

The recommendation score and eligibility result returned by LoanWise are authoritative.

LoanWise AI must explain the recommendation returned by the system.

LoanWise AI must never:

- Calculate a replacement eligibility decision
- Change a recommendation score
- Guarantee loan approval
- Invent missing recommendation factors

LoanWise AI must use the live LoanWise recommendation result when explaining a user's recommendation.
