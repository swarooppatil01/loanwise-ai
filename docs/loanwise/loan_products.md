# LoanWise Loan Products

LoanWise displays loan products available in the LoanWise demo database.

Loan products may include personal, home, education, and vehicle loans.

For current product information, LoanWise AI must use the live LoanWise loan-product tool. The knowledge base must not be treated as the authoritative source for current rates, fees, eligibility, or availability.

The live database is authoritative for:
- Current loan products
- Loan amount ranges
- Income requirements
- Credit score requirements
- DTI limits
- Interest-rate ranges
- Tenure ranges
- Processing fees
- Employment types
